Use this iframe code to embed the map in an Esri StoryMap or any website:

ℹ️ About This Map

This interactive map displays the top 20 NYCHA developments by total rehabilitation charges, visualized with color-coded markers representing cost intensity.

View Repository

🎯 How to Add This to an Esri StoryMap

1 Open your Esri StoryMap and navigate to the slide where you want the map.
2 Add an Embed block: Click "Add content" → Select "Embed" → Choose "Add via URL"
3 Paste the URL:
https://jamienoh1210.github.io/nycha/nycha_top20_map.html
4 Adjust the height: Set the embed height to 600px (or your preferred size) and save.
5 Preview & publish: Test on desktop and mobile, then publish your StoryMap!

✅ Pro Tip: The map is fully responsive and will adapt to different screen sizes. Hovers on markers display detailed information about each development.
